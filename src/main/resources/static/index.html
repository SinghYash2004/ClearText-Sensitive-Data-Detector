How ClearText works
1Detect

Java regex rules in a Spring Boot service identify possible sensitive values.

2Review

The frontend highlights matches and lets you choose which findings to redact.

3Redact & export

The backend replaces the selected values and you export the result.

This is a demonstrator, not a production-grade data-loss prevention system. Before real-world use it would need PDF/DOCX parsing, labelled test data, precision/recall evaluation, authentication, audit controls and secure retention.
